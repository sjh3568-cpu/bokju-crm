# 에이전트 운영 안내

2026-09-19 도입. **에이전트 5개 + 작업 파일 1개**로 일합니다.

## 흐름

```
① 기획 ──→ ② 구현 ──→ ③ 화면 ──→ ④ 검증 ──→ ⑤ 출시
 plan       본인!      design     verify     ship

흐름 밖:  report  (실적 보고 + 재단 대외 문서, 코드 안 건드림)
```

**② 구현만 본인이 직접 합니다.** 에이전트는 매번 기억이 백지에서 시작하는데,
구현은 맥락이 가장 많이 필요하고 중간에 끼어들어야 하는 단계라 위임이 손해입니다.

## 진짜 중심은 작업 파일

```
docs/work/2026-09-19-주제.md
```

`docs/work/_템플릿.md` 를 복사해 씁니다. 에이전트들은 **말로 인계하지 않고**
이 파일을 읽고 자기 절만 채웁니다. 백지에서 시작해도 이 파일만 읽으면 따라잡습니다.

## 부르는 법

| 방법 | 예 |
|---|---|
| 자동 | "대시보드 표가 화면을 넘어가" |
| 지명 | "design 으로 이거 정리해줘" |
| **파일 지정** (가장 정확) | "docs/work/2026-09-19-x.md 읽고 ③부터 해줘" |

익숙해지기 전에는 **파일 지정**을 습관화하세요.

## 에이전트별 설정

| 이름 | 위치 | model | tools | 못 하는 것 |
|---|---|---|---|---|
| `plan` | 저장소 | inherit | Read, Grep, Glob, Write | 코드 수정 (Edit 없음) |
| `design` | 저장소 | inherit | Read, Edit, Write, Grep, Glob, Bash | — |
| `verify` | 저장소 | inherit | Read, Grep, Glob, Bash, Write | 기존 파일 수정 (Edit 없음) |
| `ship` | 저장소 | sonnet | Read, Edit, Bash | 새 파일 생성 (Write 없음) |
| `report` | `~/.claude/agents/` | inherit | Read, Write, Bash | 코드 수정 (Edit 없음) |

**`tools` 를 제한하는 게 진짜 안전장치입니다.** 본문에 "하지 마세요"라고 쓰는 건
부탁이고, 도구를 안 주는 건 금지입니다.

## 헷갈리기 쉬운 경계

| 이런 일 | 담당 | 담당이 아닌 쪽 |
|---|---|---|
| CRM 보고서 **화면** 고치기 | ①~⑤ 흐름 | `report` 는 코드를 안 건드림 |
| 그 화면 수치가 맞나 | `verify` | `report` 는 숫자를 만들지 않음 |
| 그 수치로 경영진 보고 **문서** | `report` | `verify` 는 문장을 쓰지 않음 |
| 포스터·배너 이미지 | `design` 모드B | `report` 는 문서만 |
| 배포 | `ship` | `design`·`verify` 는 dev 까지만 |

## 운영 — 주 1회 5분

```
□ 이번 주에 한 번도 안 불린 에이전트가 있나?
   → description 을 고치거나, 그냥 지운다 (미련 갖지 말 것)

□ 엉뚱한 에이전트가 나선 적 있나?
   → 그 에이전트 description 끝에 "~일 때는 쓰지 말 것" 한 줄 추가

□ 같은 실수를 두 번 했나?
   → 본문 '절대 규칙'에 한 줄 박는다        ← 이게 규칙을 만드는 유일한 방법

□ 본문이 50줄을 넘었나?
   → 기계적인 검사 항목은 스크립트로 빼낸다 (tools/render_png.py 처럼)
```

## 규칙은 미리 쓰지 않는다

좋은 규칙을 앞에서 설계하려 하지 마세요. 경력자도 못 합니다.
**이미 당한 것만** 한 줄씩 적습니다. 한 번은 사고, 두 번은 규칙.

규칙 후보는 이미 커밋 메시지에 다 있습니다:

```
git log --oneline --grep="fix" | head -40
```

| 커밋에 적힌 말 | → 박은 규칙 |
|---|---|
| "class=nowrap 이 CSS에 없어 무효였다" | 클래스 쓰기 전 `grep` (design) |
| "다른 카드로 잘못 들어갔다" | 걸리는 템플릿 전부 세기 (design) |
| "브라우저 '오늘'을 현지 날짜로" | 날짜 어긋나면 UTC 먼저 의심 (verify) |
