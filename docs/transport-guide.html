복주회복병원 상담실 · CRM 안내

입원 확정 환자 차량 픽업, CRM에서 한 번에

안동·예천 인근 모병원에서 모셔오는 환자는 지금까지 운행팀 구글 시트에 따로 적었습니다. 이제 상담 상세 화면의 🚐 차량 운행(픽업) 요청 칸만 채우면 시트에는 자동으로 들어갑니다. 시트를 열 필요가 없습니다.

언제 하나 입원 확정 직후, 병실까지 정해졌을 때

차량이 필요한 환자

모병원 병동에서 우리 차량으로 이동. 이동수단·호실·도착시간을 적고 저장하면 운행팀 시트 「진료협력」 줄로 들어갑니다.

보호자가 직접 오는 환자

불필요를 골라 저장합니다. 이걸 해 두어야 대시보드에 "운행 여부 미정" 경고가 뜨지 않습니다.

순서 1분이면 끝납니다

  1. 환자의 상담 상세 화면을 엽니다

    상담 목록에서 환자 이름 클릭 → 아래로 내려가 🚐 차량 운행(픽업) 요청 카드.

  2. 「차량 필요」 또는 「불필요」를 고릅니다

    불필요면 바로 저장. 끝.

  3. 비어 있는 칸만 채웁니다
    날짜(탭)
    자동 입원예정일. 시트의 날짜 탭이 됩니다.
    이동수단
    입력 W/C · walking · Recliner 중 선택
    요청이유
    자동 픽업(입원). 다르면 바꿉니다.
    요청 장소
    입력 모병원 이름은 채워져 있음 — 호실만 추가 예: 안동병원 605호
    도착시간
    입력 시간만 고르면 "14:00 도착"으로 들어갑니다
    연락처
    자동 보호자 관계·번호. 준비물은 뒤에 덧붙입니다 예: (산소 3L 준비)
    요청부서·요청자
    자동 진료협력 · 로그인한 본인 이름
  4. 「저장 · 시트 전송」

    "전송 완료 (2026.9.14 탭 15행)" 알림이 뜨면 시트에 들어간 것입니다. 잘못 적었으면 고쳐서 다시 저장 — 새 줄이 생기지 않고 그 줄이 고쳐집니다.

상태 읽기 카드 상단 띠와 입원 대기 탭의 🚐 표시

표시뜻할 일
🚐?운행 여부 미정필요/불필요 중 하나를 저장
🚐!전송 대기 — 시트에 그 날짜 탭이 아직 없음운행팀에 탭을 만들어 달라고 요청. 탭이 생기면 1시간 안에 자동 전송
🚐…시트에 들어갔고 운행팀 배정 대기없음. 운행팀이 배정자·차량을 채우면 자동으로 바뀜
🚐✓배정 완료 — 카드에 "배정: 이름 / 차량" 표시보호자에게 시간·장소 안내
🚐✕운행 불필요 (보호자 직접)없음

오늘·내일 입원 예정인데 🚐? 또는 🚐!인 환자는 대시보드 「오늘 처리 필요」에 빨간 줄로 올라옵니다.

자주 묻는 것

입원 날짜가 바뀌면?상담에서 입원예정일을 고친 뒤 🚐 카드의 날짜(탭)도 새 날짜로 바꿔 다시 저장합니다. 이전 날짜 탭의 줄은 시트에서 직접 지워 주세요.
시트에 있던 줄을 운행팀이 지웠는데 CRM은 "전송 완료"로 남아 있어요.카드에서 다시 저장하면 새 줄로 들어갑니다.
배정자가 안 보여요.운행팀이 채운 뒤 최대 1시간 뒤에 반영됩니다. 급하면 시트를 직접 보셔도 됩니다.
퇴원 귀가 운행도 여기서?요청이유를 「퇴원」으로 바꾸고 날짜(탭)를 퇴원일로 지정하면 같은 방식으로 들어갑니다.
