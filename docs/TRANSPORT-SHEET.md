# 차량 운행(픽업) 요청 — 구글 시트 연동 설치

상담사가 CRM 상담 상세의 **🚐 차량 운행(픽업) 요청** 칸을 저장하면, 운행팀 구글 시트
「복주 운행 공유」의 해당 날짜 탭에 **진료협력** 행이 자동으로 들어갑니다.
운행팀이 채운 배정자·차량은 1시간마다 CRM으로 읽어와 표시합니다.

- 시트 **소유자가 아니어도** 됩니다. 편집 권한이 있는 본인 구글 계정으로 아래를 진행합니다.
- 탭은 절대 만들지 않습니다. 날짜 탭이 없으면 "전송 대기"로 두었다가 탭이 생기면 자동으로 넣습니다.
- 시트 B~I 열(요청부서~연락처)만 쓰고, J~M(운행팀 칸)은 손대지 않습니다.

## 1. Apps Script 만들기 (5분, 한 번만)

1. 브라우저에서 https://script.google.com 접속 (시트 편집 권한이 있는 계정으로 로그인)
2. **새 프로젝트** → 왼쪽 위 이름을 `복주 운행 연동`으로 변경
3. 편집창의 내용을 모두 지우고 `docs/apps-script/transport_sheet.gs` 내용을 붙여넣기
4. 맨 위 두 줄 수정
   - `SHEET_ID` : 시트 주소 `https://docs.google.com/spreadsheets/d/`**이 부분**`/edit` 을 붙여넣기
   - `TOKEN` : 아무 긴 문자열 (예: 비밀번호 생성기로 32자) — CRM `.env`에도 같은 값을 넣습니다
5. 저장(💾)

## 2. 웹앱으로 배포

1. 오른쪽 위 **배포 → 새 배포**
2. 톱니(유형 선택) → **웹 앱**
3. 설정
   - 설명: `crm`
   - **다음 사용자 인증 정보로 실행: 나** ← 중요 (내 편집 권한으로 시트에 씀)
   - **액세스 권한이 있는 사용자: 모든 사용자** ← 중요 (CRM 서버가 로그인 없이 호출)
4. **배포** → 권한 승인 창에서 계정 선택 → "확인되지 않은 앱" 경고가 뜨면
   **고급 → (프로젝트명)(으)로 이동(안전하지 않음)** → 허용
5. 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`) 복사

> 스크립트를 나중에 고치면 **배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포** 를 해야 반영됩니다. URL은 그대로입니다.

## 3. CRM에 연결

`.env`에 추가하고 서버를 재시작합니다.

```
TRANSPORT_SHEET_URL=https://script.google.com/macros/s/……/exec
TRANSPORT_SHEET_TOKEN=(1-4에서 정한 값)
TRANSPORT_MOBILITY_OPTIONS=W/C,walk,Rec
```

`TRANSPORT_MOBILITY_OPTIONS`는 시트 '이동수단' 드롭다운에 있는 값과 **글자까지 똑같이** 적습니다
(시트 쪽 데이터 확인 규칙에 걸리지 않게).

## 4. 점검

CRM에 로그인한 브라우저에서 개발자도구 콘솔(F12)에 아래를 넣어 실행:

```js
fetch('/api/transport/ping', {method:'POST'}).then(r=>r.json()).then(console.log)
```

- `{ok:true, sheet:"복주 운행 공유", tabs:N, tab_for_date:"2026.9.14"}` 이면 정상
- `BAD_TOKEN` → 토큰이 양쪽에서 다름
- `응답이 JSON이 아님` → 2-3의 "액세스: 모든 사용자"가 아님
- `tab_for_date: null` → 오늘 탭이 아직 없음 (정상, 운행팀이 만들면 됨)

## 5. 상담사 사용법

1. 입원 확정된 환자의 상담 상세 → **🚐 차량 운행(픽업) 요청**
2. **차량 필요** 선택 → 이동수단 · 요청 장소(모병원은 채워져 있고 호실만) · 도착시간 · 연락처 확인 → **저장 · 시트 전송**
3. 보호자가 직접 오면 **불필요** 를 저장 (그래야 대시보드 경고가 꺼짐)
4. 저장 후 상태
   - 🟢 시트 전송 완료 · 배정: 권철호 / 6668 — 끝
   - 🟡 시트 전송 완료 · 운행팀 배정 대기 — 운행팀이 채우면 자동 반영
   - 🔴 전송 대기 (탭 없음) — 운행팀에 그 날짜 탭 요청. 탭이 생기면 1시간 안에 자동 전송

## 6. 대시보드 경고

오늘·내일 입원 예정 환자 중
- 운행 여부 **미정** → 빨강
- 차량 필요인데 **전송 대기/실패** → 빨강
- 전송됐는데 **배정자 없음** → 노랑

## 문제 해결

| 증상 | 원인 | 조치 |
|---|---|---|
| 모든 저장이 "전송 실패: HTTP 401/403" | 배포 액세스가 '모든 사용자'가 아님 | 배포 관리에서 수정 후 새 버전 배포 |
| 갑자기 전송 실패 시작 | 시트 편집 권한이 회수됨 | 시트 소유자(이사님)에게 편집 권한 재요청 |
| 행이 엉뚱한 탭에 들어감 | 탭 이름이 날짜 형식이 아님 | 탭 이름은 `2026.9.14` 또는 `2026.09.14` 형식 유지 |
| 같은 환자 행이 두 개 | 이름을 바꾼 뒤 재저장 | 시트에서 이전 행 삭제 |
