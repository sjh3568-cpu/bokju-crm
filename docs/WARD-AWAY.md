# 외진환자관리 (v1.5.0)

재원 관리 드롭다운 또는 재원 관리의 **외진환자관리** 탭(`/ward?tab=away`)에서 연다.
개인 설정의 재원관리 기본 화면에서도 선택할 수 있다.

## 기록과 조회

- 기존 `admission_events`의 응급전원·모병원 외래치료 기록을 사용한다. 복귀 완료와 실제 퇴원 이후 이력도 유지한다.
- 환자명, 성별, 상담에 기록된 나이, 입원일, 전원·외진일, 실제 퇴원일, 이송기관, 사유, 병명, 퇴원 D-day, 복귀일을 표시한다.
- 입원일·병명·퇴원 D-day는 연결된 상담 정보를 사용한다. 외진 기간은 재원 기간에서 차감하지 않는다.
- 수정 권한이 있으면 재원 환자의 외진 기록을 등록하고 복귀일을 저장할 수 있다. 조회 권한에는 저장 버튼을 표시하지 않고 API도 쓰기를 차단한다.
- 이미 미복귀 기록이 있는 입원 건은 복귀 처리 후 새 외진을 등록한다.
- 작성 중 내용이 사라지지 않도록 이 탭의 주기적 자동 새로고침은 사용하지 않는다. 저장 후에는 화면을 갱신한다.

## 통계 기준

- 기간은 전원·외진 발생일 기준이며 기본값은 전체 기간이다. 종료일을 포함한다.
- 환자 수는 환자 ID의 중복을 제거한다. 복귀 환자 수는 해당 기간에 나간 기록 중 **한 번 이상 복귀한 환자**다.
- 반복 전원 횟수는 별도 건수로 표시한다. 복귀 후 다시 나간 환자는 복귀 인원과 미복귀 기록 보유 인원에 동시에 포함될 수 있다.
- 환자 복귀율 = 복귀 실인원 / 전체 실인원. 건 복귀율 = 복귀 건수 / 전체 건수. 기록이 없으면 0%다.
- 응급전원만의 통계를 별도 표시한다. 일반 퇴원 데이터에서 전원을 추정하지 않는다.
- 기간·유형은 통계에 적용하며, 검색어·복귀 상태는 명부에만 적용하여 통계 분모를 유지한다.
- 월별 현황은 나간 달의 기록에 대한 이후 복귀를 집계한다. 여러 달에 전원한 환자는 각 월에 포함되어 월별 인원 합과 전체 실인원이 다를 수 있다.
- 발생일이 없는 과거 기록은 전체 기간에서 '일자 미기재'로 표시하며, 날짜 범위를 지정하면 제외한다.

## 검증

`python -m unittest discover -s tests -v`

`tests/test_ward_away.py`에서 반복 전원·실인원 집계, 퇴원 후 이력, 기간·상태·검색 필터,
월별 집계, HTML 이스케이프, 권한, 복귀일 검증과 저장, 중복 외진 방지를 검사한다.
실제 환자 DB와 분리한 브라우저 검증에서 등록·복귀 저장 및 PC·모바일 렌더링을 확인했다.
