# 상담내역 구글 시트 → CRM 자동 반영 (과도기)

상담사가 아직 구글 시트 **"상담내역 종합"**에 상담을 적는 동안, 시트에 적은 것이 CRM에도 들어오게 한다.
시트 쪽은 Apps Script 웹앱이 시트 전체를 JSON으로 돌려주고(읽기만), CRM이 10분마다 받아 간다.
운행 시트 연동(docs/TRANSPORT-SHEET.md)과 같은 방식이라 구글 클라우드 계정·키 파일은 필요 없다.

## 무엇이 어떻게 반영되나

| 시트에서 | CRM에서 |
|---|---|
| 새 행을 적음 | 환자·상담을 새로 만든다(같은 환자·같은 상담일이 이미 있으면 중복으로 보고 만들지 않음) |
| 있던 행의 칸을 고침 | 그 행에 연결된 상담의 **바뀐 칸만** 고친다. CRM에서 따로 고친 칸은 지키고 '충돌'로 보고 |
| 행을 지움 | CRM에서 지우지 않는다. '시트에서 사라짐'으로만 보고 |
| 예전에 엑셀 적재로 들어온 상담 | 처음 만나면 그 행과 **연결만** 하고 값은 바꾸지 않는다(그 뒤 고친 칸부터 반영) |
| '입원환자 대기 명단' 탭 | 건너뛴다(엑셀 적재 화면에서 따로 적재) |

상태(입원여부)가 바뀌면 엑셀 적재와 같이 입원 회차·환자 생애주기도 맞춘다.
행은 `이름|상담일` 키로 찾고, 이름이나 날짜를 고친 행은 같은 자리(행 번호)로 다시 찾는다.
이름과 위치를 동시에 바꾸면 새 행으로 들어올 수 있다 — 그럴 땐 미리보기 결과에서 확인한다.

## 설치 (한 번)

1. **시트에 스크립트 붙이기** — 시트 "상담내역 종합" 소유 계정으로:
   확장 프로그램 → Apps Script → `docs/apps-script/consult_sheet.gs` 내용을 붙여 넣고
   `SHEET_ID`(시트 주소의 `/d/<이 부분>/edit`)와 `TOKEN`(아무 긴 문자열)을 채운다.
2. **권한 승인** — 편집기 위쪽 함수 목록에서 `checkAccess`를 고르고 ▶실행. 권한 검토 창 → 계정 선택 →
   "확인되지 않은 앱" 경고가 뜨면 **고급 → (프로젝트명)(으)로 이동(안전하지 않음) → 허용**. 실행 로그에 시트 이름과
   탭 수가 찍히면 된다. (이 단계를 건너뛰면 CRM이 "SpreadsheetApp.openById 권한이 없습니다"를 받는다.)
3. **웹앱으로 배포** — 배포 → 새 배포 → 유형 '웹 앱', 실행 사용자 '나', 액세스 '**모든 사용자**' → 배포.
   나온 웹앱 URL(`https://script.google.com/macros/s/…/exec`)을 복사한다.
   (액세스를 '모든 사용자'로 두지 않으면 CRM이 JSON 대신 로그인 페이지를 받아 "응답이 JSON이 아님"이 뜬다.
   토큰이 있어야만 응답하므로 URL이 알려져도 시트가 열리지는 않는다.)
4. **CRM .env** (운영은 `/volume1/docker/bokju-crm/.env`):
   ```
   CONSULT_SHEET_URL=<웹앱 URL>
   CONSULT_SHEET_TOKEN=<스크립트의 TOKEN>
   CONSULT_SHEET_MINUTES=10
   ```
   넣은 뒤 서버(컨테이너)를 다시 시작한다.
5. **관리 → 엑셀 적재** 화면 맨 위 '구글 시트 자동 반영' 카드에서
   **미리보기** → 결과 확인 → **지금 반영** → **자동 반영 켜기** 순서로 진행한다.
   자동 반영은 이 버튼으로만 켜진다(.env만으로는 안 켜짐). 켜고 끄는 데 재시작은 필요 없다.

## 운영하면서

- 카드에 마지막 실행 결과(새 상담·고친 행·충돌·사라짐)와 자세한 목록이 남는다. 반영이 있으면 감사 이력(`sheet_sync`)에도 남는다.
- 충돌 = 시트와 CRM 양쪽에서 같은 칸을 고친 경우. CRM 값을 지키고 목록에 한 번 보고한다(다음 실행부터는 시트 값을 기준선으로 본다).
  시트 값이 맞으면 CRM에서 그 칸을 고쳐 준다.
- 반영 전 DB 백업은 12시간에 한 번만 남긴다(`backups/pre_sheet_sync_*`). 일일 백업은 따로 돈다.
- 상태 파일: `data/consult_sheet_sync.json` (auto 켜짐 여부, 마지막 결과). 행 ↔ 상담 연결: 표 `consult_sheet_links`.
- 시트 사용을 끝내고 CRM 직접 입력으로 넘어가면 자동 반영을 끄고 .env 두 줄을 비우면 된다. 연결 표는 남아도 무해하다.

## 왜 이렇게 만들었나 (2026-09-28)

- 사용자 결정: 새 행 추가 + 고친 행 반영, 과도기용. 삭제는 반영하지 않는다.
- 엑셀 적재 도구(`tools/excel_import.py`)의 시트 해석(`parse_sheet`)을 그대로 써서 수동 적재와 결과가 같다.
- 시트가 진실이 되지 않게 '바뀐 칸만, CRM에서 안 고친 칸만' 반영한다 — 입원완료·퇴원 처리처럼 CRM에서 진행한 것이
  시트의 옛 값으로 되돌아가지 않게.
