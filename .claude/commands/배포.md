---
description: 운영(NAS)에 최신 버전을 배포한다 (병원 PC에서 한 마디로)
---

운영 서버(NAS)에 **최신 릴리스 태그**를 배포한다. 아래 한 줄을 실행하면 NAS가
백업 → 코드 교체 → 재빌드 → 재시작 → 기동 확인까지 스스로 한다.

실행할 명령:

```
ssh bokju-nas "sudo -n /root/deploy.sh --yes"
```

진행 방법:
1. 위 명령을 그대로 실행한다.
2. 출력(백업 경로·버전·"배포 완료" 또는 에러)을 사용자에게 한국어로 간단히 정리해 보여준다.
3. "✅ 배포 완료 — vX.X.X" 가 보이면 성공. 화면 하단 버전이 그 번호인지 확인하라고 안내한다.
4. `bokju-nas` 를 못 찾거나 비밀번호를 물으면 → 이 PC의 SSH 연결이 아직 안 잡힌 것이니
   그 메시지를 사용자에게 보여주고, 임의로 우회하지 말 것.
5. 배포 후 문제가 생겨 되돌려야 하면(사용자가 요청할 때만):
   `ssh bokju-nas "sudo -n /root/deploy.sh --rollback"` (직전 태그로 복구).

주의:
- 이 명령은 **최신 태그**를 배포한다. 특정 버전을 원하면 사용자에게 버전을 물어
  `--yes` 앞에 그 태그(예: `v1.8.8`)를 넣는다.
- 상담 업무시간(09~18시)이면 재시작 순간 저장이 유실될 수 있음을 한 번 알린다(그래도 진행은 한다).
- 배포는 이 한 줄이면 끝이다. File Station 복사·Container Manager 클릭 같은 수동 절차는 필요 없다.
